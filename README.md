Live-synced lyrics displayed on a wallpaper using Spotify.

Livic uses unofficial methods to retrieve lyrics and track data from Spotify. This project is intended for personal, educational use only.

It is not affiliated with Spotify. Unofficial APIs may break at any time. Using them may violate Spotify's Terms of Service — use at your own risk.

This is a personal project but suggestions and PRs are welcome once it's off the ground.
